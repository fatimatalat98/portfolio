# Fatima Talat Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Features
- Modern responsive design
- Dark/light theme
- Project filters and search
- Personal/collaborative badges
- Detailed project case-study pages
- GitHub links
- Mobile navigation

## Edit your project details
All project content is in `projects.js`. Update the collaborative project descriptions with your exact personal contribution before publishing.

## Run
Open `index.html` or use VS Code Live Server.

## Deploy with GitHub Pages
Push the files to a repository, then enable **Settings -> Pages -> Deploy from branch -> main / root**.
